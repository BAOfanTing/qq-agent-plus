# 拟人化表达：评估与调参

这份文档只解决一个问题：改了提示词/状态/发送节奏之后，怎么判断“更像人”而不是只靠感觉。

## 1. 先跑客观指标

准备一份**脱敏**样本文件（每行一个 JSON，或一个 JSON 数组）：

```jsonl
{"messages":["在吗？","今天怎么没说话"]}
{"text":"刚吃完饭，懒得动。"}
```

然后：

```bash
node scripts/humanize-eval.mjs samples.jsonl
# 或 npm run humanize:eval -- samples.jsonl
# grounded / card 档保留了"首先/其次"，用 --severe-only 只看真正的自指/免责
node scripts/humanize-eval.mjs samples.jsonl --severe-only
```

输出：

- `avgChars` / `medianChars` / `maxChars`：长度分布；
- `questionRate`：带问号的回复比例（全是对答或全是反问都不像真人）；
- `multiBubbleRate`：分条发送比例；
- `aiTellRate`：命中助手腔词表的比例；
- `duplicateOpenerRate`：开头 6 个字重复的比例；
- `cjkRate`：中文样本占比（防止把英文模板混进来）。

这些是**观察线**，不是硬门禁。先记录当前版本的数字，改完再对比。

## 2. 盲评

从真实群聊里抽 30–50 组“上下文 + 回复”，至少两人独立盲评，不看版本号。每组按 1–5 分打：

| 维度 | 1 分 | 5 分 |
| --- | --- | --- |
| 像真人 | 明显客服/AI 腔 | 像群友随口说的 |
| 人设一致 | 和角色卡矛盾 | 口吻、称呼、态度都对得上 |
| 长度 | 过长/过短 | 和上下文匹配 |
| 重复 | 反复同一开场白/句式 | 有变化 |
| 动作 | 乱发表情/语音/拍一拍 | 该用时用、不该用时不用 |

至少比较两组：当前线上版本 vs 候选版本。不要只让一个人评，也不要把“评委觉得像”当成唯一目标——最终看真实群里的反馈。

## 3. 调参顺序

1. 先看 `aiTellRate` 和 `duplicateOpenerRate`：这两项最容易量化，也最影响“AI 味”。
2. 再看长度和分条：一条 300 字的长段通常比三条短句更像客服。
3. 最后看状态/关系：这两项影响的是“记得这个人”，不是单句像不像人。
4. 角色卡优先（`behaviorProfile: 'card'`）时，先确认 `humanize.respectPersonaCard` 是开的，否则平台会改掉卡的语气。

## 4. 已知边界

- 评估脚本只看文本，不判断动作是否合适；动作频率要结合 `用量` 页和群里的实际反馈。
- 盲评样本必须脱敏，不要把真实 QQ 号、群号、Key 放进仓库。
- 当前没有自动“重跑直到达标”的循环：反 AI 味只做一次定向重写，避免成本和死循环。

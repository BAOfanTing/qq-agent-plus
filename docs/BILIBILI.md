# B 站插件

官方插件，`examples/plugins/bilibili`，apiVersion 2。范围是**读 + 观看 + 互动**；不做投稿、发动态。

## 快速开始：聊天里扫码登录

对机器人说「登录B站」→ 它在当前会话发一张二维码 → 手机 B 站 App 扫码并在手机上确认 → 再说「好了」。
Cookie 由宿主加密保存、立即生效，全程不经过任何第三方。控制台插件设置里手动粘 Cookie 的老办法仍可用；
`login status/logout` 随时查/退。

## 能做什么

| 工具 | 作用 | 需要登录 |
| --- | --- | --- |
| `search` | 搜索视频（标题、BV 号、UP 主、播放量、时长） | 否 |
| `video` | 视频详情、分 P、统计、评论、字幕语言 | 否（字幕正文需要） |
| `user` | UP 主资料与最近投稿 | 否 |
| `popular` | 综合热门 / 排行榜 | 否 |
| `account` | 历史、收藏夹、关注列表 | 是 |
| `read` | 两段式看懂视频：字幕全文（无字幕走宿主语音转写）＋弹幕密度采样＋热评楼中楼；需要画面时传 `frames:["02:31"]` 抽帧并转成文字描述 | 否 |
| `login` | 聊天内扫码登录 / 查登录态 / 退出 | 否 |
| `watch` | 取 DASH 音视频，宿主合流 mp4，按设置发到当前群 | 否（高清需要） |
| `interact` | 点赞 / 投币 / 收藏 / 关注（可取消） | 是 |
| `comment` | 发评论 | 是 |
| `danmaku` | 读弹幕 / 发弹幕 | 发弹幕需要 |

## 配置

安装后在插件详情页的「插件设置」里填：

- **账号**：`SESSDATA`、`bili_jct`（CSRF，写操作必须）、可选 `buvid3`、`DedeUserID`（收藏夹/历史/关注需要）。
  浏览器登录 B 站 → 开发者工具 → Application → Cookies 复制。凭据由宿主加密保存，页面只显示"已配置"。
- **观看与发送**：默认清晰度（未登录一般只能取到 480P）、是否允许把视频发到群里（默认关）、单文件上限（5-80MB）。
- **读内容偏好**：每次读评论 / 弹幕的条数。

## 写操作：先批准，再计数

点赞、投币、收藏、关注、评论、发弹幕都属于写操作：

1. 详情页「需要批准的动作」里点「批准一次」或「批准 10 次」，默认 10 分钟内有效；
2. 插件每次写操作消费一次批准；过期或次数用完会直接失败，不自动重试；
3. 当天还有配额（互动 30、评论 10、弹幕 20），宿主按插件 + 动作 + 日期计数，跨天归零；
4. 每次调用都会在宿主日志里留一行（`[plugin:bilibili] POST api.bilibili.com...`）。

没有批准时，模型收到的是一句可读原因，不是静默失败。

## 观看视频

`watch` 走 `cap.media.download` 下载 DASH 视频与音频，再由宿主 `ffmpeg -c copy` 合流：

- 需要服务器装 `ffmpeg`/`ffprobe`（巡检的 media-tools 一项会显示）；
- 清晰度越高文件越大，默认上限 60MB；超限换更低清晰度；
- 只有**群聊**且设置里打开了「允许把视频发到群里」才会发文件；私聊/关闭时只返回标题、时长、链接；
- 文件保留在 `data/plugin-data/bilibili/media/`，只保留最近 5 个。

## 边界与已知限制

- 不支持番剧/付费内容/地区限制视频（DASH 流拿不到）；
- 被 B 站风控（-352）时返回可读错误，不会自动重试；
- 弹幕读取依赖 `x/v1/dm/list.so` 返回 XML；如果上游改成压缩/二进制，会明确报"没读到弹幕"而不是编内容；
- Cookie 会过期：写操作报 `账号未登录` 时重新复制一次即可；
- 不做自动投稿、自动发动态、自动三连（必须逐个动作批准）。
